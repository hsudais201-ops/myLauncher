# Hyper Launcher

A responsive, desktop-first UI prototype for a Minecraft Java Edition launcher.

## Preview

Open [index.html](./index.html) in a browser, or enable GitHub Pages for this repository to publish the static preview.

## Included in this first UI build

- Dark, game-inspired desktop layout with a custom pixel landscape.
- Responsive navigation for Home, Instances, Mods & Packs, and Settings.
- Version selector and interactive memory allocation slider.
- Offline Player profile placeholder.
- Play buttons and dialogs that clearly explain which launcher features are not implemented yet.

## Important status

This is a **front-end prototype only**. It does not currently download game files, launch Minecraft, authenticate Microsoft accounts, or implement an offline profile system. Those require a separate launcher runtime and careful account/session handling.

## Files

- `index.html` — page structure
- `styles.css` — responsive styling
- `app.js` — preview interactions

No branches were deleted. Work was committed to `main`.
