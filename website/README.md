# VoidCraft official website

Static, mobile-first website for VoidCraft Launcher. Pages include home, downloads, Feature Store, Cosmetic Store, server status, community, developer hub, documentation, security, changelog, profile, sign-in information, privacy, terms, and 404.

Cloudflare Pages project: `voidcraft-website`. Site files are kept in `website/`, separate from launcher source and runtime files.

Authentication, purchases, user uploads, live server ping, feature package installation, and launcher-linked actions are prototypes until a secure backend is implemented. Do not represent these as active services.
