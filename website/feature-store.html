Files & modding

Advanced Mod Manager

Organize Minecraft Java mod JAR files in a private browser library. Import files, enable or disable entries, export copies, and remove them. Your mod files are not uploaded to VoidCraft.

Files stay in this browser's IndexedDB. Export JARs to import them into the launcher's Mod Manager.

Personalization

Cosmetic Store

Browse the cosmetic catalog, view release details, and equip cosmetics after the signed-in account has a confirmed purchase.

No separate installation is required. Equip currently changes the VoidCraft website profile only; Minecraft player-model and multiplayer rendering are not yet included.

Open Cosmetic Store → No install required

Multiplayer

Server State

Check Minecraft Java and Bedrock server status, player counts, version and message of the day. Save up to 30 server addresses in this browser and refresh on demand.

Status requests share the server address with the public mcsrvstat.us service. Results may be delayed or unavailable.
