NEW · OPTIONAL TOOL

Advanced Mod Manager

Organize your Minecraft Java mod JAR files in a private browser library. Import files, enable or disable them in your collection, export copies, and remove items. Nothing is uploaded to VoidCraft.

Works in your browser: files are saved locally using IndexedDB. For Android, import exported JARs into the launcher’s optional Mod Manager.

Open Mod Manager →Browser tool available · Android beta
OPTIONAL · PERSONALIZATION

Cosmetic Store

Browse cosmetic listings and equip original VoidCraft profile effects in your browser. Includes Void Aura, Neon Mint, Arctic Ice and Solar Ember. Equipped styles are local website profile effects—not Minecraft in-game cosmetics.

NEW · OPTIONAL TOOL

Server State

Check live Minecraft Java and Bedrock server status, online player counts, versions and MOTD. Save up to 30 server addresses in your browser and refresh them on demand.

Browser tool available: addresses stay in this browser; status checks send the server address to the public mcsrvstat.us service. Results may be delayed or unavailable.

Not installed

NEW · OPTIONAL PERSONALIZATION

Theme Studio

Customize the VoidCraft website with color presets or your own palette. Preview changes live, save your colors locally, and apply them across supported website pages.

Browser-based: saved themes stay in this browser. This changes website colors only, not Minecraft textures or resource packs.

Not installed
