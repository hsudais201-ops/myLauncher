BEFORE YOU INSTALL

A quick release checklist.

Only install an APK that is actually attached to an official release and matches your device. If there is no APK asset, do not substitute a random mirror.

01

Check the release tag

Confirm the version label and read the release notes to see what changed and what remains untested.

02

Check the APK asset

Verify that the release actually includes an Android APK. A repository ZIP or source archive is not an installable Android package.

03

Check your device

Review Android compatibility, storage and permissions. Keep a backup of important worlds before switching launchers or versions.

04

Report a problem

If an official build fails, include the release tag, device details and safe reproduction steps in a bug report.
