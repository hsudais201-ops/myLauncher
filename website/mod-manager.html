Important compatibility note

This is a working browser-local library manager. A web page cannot write directly into Android app-private storage or install files into your Minecraft profile. To use a mod with the VoidCraft Android launcher, export it here and import the JAR through Advanced Mod Manager in the launcher. The launcher’s Minecraft runtime/profile integration is still in development, so enable/disable switches here organize this browser library only; they do not activate mods in-game.

Only use mods from sources you trust, and check the mod loader and Minecraft version before using a file.
