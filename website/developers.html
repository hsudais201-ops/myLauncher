CREATOR WORKSPACE

Submit a store item

Your submission remains private until an owner reviews and publishes it. Provide enough detail for users to assess trust, compatibility and permissions.

This form submits links and listing metadata. Binary file uploads are not enabled yet; provide a public HTTPS package URL or leave it blank. A published package link is not automatically security-audited. Do not submit secrets, access tokens, or private URLs.

BEFORE SUBMITTING

Review checklist

  • Source code and a clear license
  • Permission and network access declaration
  • Supported launcher / Minecraft versions
  • Reproducible tests and known limitations
  • Original assets and distribution rights
  • No secrets or credentials inside packages
⚿

Protected publishing

Submission requires sign-in. Only the owner role can publish or reject pending listings. New items are not public before approval.
