THE PROJECT

A launcher foundation with a distinct VoidCraft identity

VoidCraft is being developed around the existing launcher foundation instead of replacing its essential runtime internals without a technical reason.

◈
CORE FOUNDATION

Keep the essential engine working

Preserve the existing runtime approach, renderer/native components, libraries, version metadata and working compatibility code while building original VoidCraft screens and features around it.

Preservation principle
▣
ANDROID-FIRST

Designed for phones, tablets and Chromebook

Prioritize responsive layouts, readable controls, touch-friendly navigation and clear device compatibility information. Actual support depends on the device, Android environment and build.

Design direction
⚙
TRANSPARENCY

Clear status, not empty promises

Separate working functions, prototypes and planned work. A preview or settings screen alone will not be treated as proof that a feature launches successfully in-game.

Project quality goal
LAUNCHER ROADMAP

What VoidCraft is building toward

The following describes target functionality. Availability must be verified in the actual launcher build before it is called complete.

▶

Versions and launch flow

Work toward choosing compatible Minecraft Java versions, checking required files, reporting downloads clearly, and surfacing launch errors with useful diagnostics.

In development / validation required
▤

Instances and profiles

Target separate game profiles with version, loader and per-instance preferences, plus safe clone, import, export and organization options without overwriting a user's worlds.

Planned / verify per build
◇

Mods, loaders and modpacks

Target supported loader and modpack workflows with version compatibility checks, clear install results and recovery paths. Support will vary by Minecraft version and device.

Planned / compatibility dependent
⌁

Touch controls

Target touch layouts that are easier to adapt to different screens, with a touch-control designer and practical in-game usability checks.

Planned
▧

Worlds, settings and backups

Target world-safe management, backup and restore guidance, configurable memory and launch settings where supported, and safeguards against accidental data loss.

Planned
◉

Performance and stability

Target compatibility-aware performance guidance, reversible settings and useful diagnostics. FPS and stability claims require repeatable testing on real supported devices; no universal FPS guarantee is made.

Planned / testing required

ACCOUNT AND SECURITY

Your website username is created with your account

Registration asks for a username, email and password together. The username is saved to the website profile; use the same username when signing in.

What your website account does

It provides registration, sign-in, a session and a basic profile. A visible website role such as Owner is part of this website account.

What it does not do yet

It is not Microsoft, Xbox or Minecraft authentication, does not prove game ownership, and does not currently sign into the Android launcher.

Security notes

Passwords are stored as salted chained PBKDF2-HMAC-SHA-256 hashes, not plain text. Session cookies are Secure, HttpOnly and SameSite. Email verification and password reset still need implementation.
