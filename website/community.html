HELP US FIX IT

A useful bug report is specific.

Keep reports focused and remove private information before sharing them in a public issue.

Tell us what you used

Include the page or launcher version, device and Android version, Minecraft version if relevant, and whether you were signed in.

List clear reproduction steps

Write the steps in order, what you expected, and what actually happened. A short screen recording can help if it contains no sensitive information.

Redact secrets first

Never post passwords, email reset codes, session cookies, access tokens, private chat details or unredacted logs that contain account data.

Social Hub beta notice: it is still a staging service with separate beta credentials. Email verification, password recovery, push notifications and end-to-end encryption are not implemented. Avoid sending sensitive information and use the report/block tools when needed.
